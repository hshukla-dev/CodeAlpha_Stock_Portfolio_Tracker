# CodeAlpha_Stock_Portfolio_Tracker

A console-based Stock Portfolio Tracker built in Python for my **CodeAlpha Python Programming Internship** (Task 2).

## Features
- Uses a predefined dictionary of stock ticker prices.
- Accepts multiple stock symbols and share quantities with input validation.
- Calculates individual holding values and total portfolio investment.
- Exports the portfolio summary to `portfolio_summary.csv`.

## How to Run
```bash
python stock_tracker.py
